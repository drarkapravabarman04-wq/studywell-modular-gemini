SIR Novice (0h)

S-I-R Framework (Spaced Repetition, Interleaving, Retrieval)

Fundamental 1: Build an effective retrieval method

Core methodology combining the spacing effect, effortful active recall without notes, and interleaved practice to maximize long-term retention.

CORE PRINCIPLES:
  • Use spacing effect correctly: adjust intervals dynamically based on recall performance
  • Effortful retrieval practice: close books and sketch/explain before checking reference notes
  • Test true recall vs familiar recognition to avoid illusion of competence

INTERLEAVING Novice (0h)

Interleaving (Declarative vs Procedural)

Fundamental 1: Build an effective retrieval method

Maximizing retention by alternating between topic types using declarative and procedural interleaving methods.

CORE PRINCIPLES:
  • Declarative interleaving: alternate across sub-disciplines (e.g. Anatomy relations + Physiology mechanisms)
  • Procedural interleaving: practice mixed clinical scenarios and diagnostic trees out of sequence
  • Embrace perceived difficulty: interleaving feels slower initially but yields substantially higher exam retention

MARGINAL_GAINS Novice (0h)

Marginal Gains Framework

Fundamental 1: Build an effective retrieval method

Tracking and targeting skill development systematically to achieve continuous micro-improvements in study efficiency.

CORE PRINCIPLES:
  • Isolate specific micro-skills (e.g., speed of drawing schema, accuracy of self-testing)
  • Track efficiency gains over time rather than raw hours spent
  • Target weakest retention areas instead of repeatedly reviewing comfortable material
